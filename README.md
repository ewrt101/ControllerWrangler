# Controller Wrangler
Software for connecting a XBOX or other PC controller to the [OpenGlover Driver](https://github.com/LucidVR/opengloves-driver) or RadVR driver. <br>
Check out the docs if you want the more nerd info and my ramblings

- Support VMC for VR gloves support


## Build

1. Clone the repository:

   ```bash
   git clone https://github.com/ewrt101/ControllerWrangler.git
   cd ControllerWrangler
   ```

2. Install any required dependencies for your platform, like .NET10.

3. Build the project:

   ```bash
   dotnet build
   ```

4. Run the application:

   ```bash
   dotnet run
   ```

If you are using Visual Studio Code, launch configs are included
